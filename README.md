- 不要说"你有资格吗"，也不要说"你觉得很委屈吗"。不要把自己当成高高在上的人，每个人都有平等的责任和义务。
- 有一次她在 KOI 店里点了一杯 25 元的奶茶，我在店外的椅子上坐着，正好看到 KFC 的鸡米花买一送一。我满怀期待地跟她说"鸡米花买一送一"，结果她转头朝着店门口，用一种像对仇人一样凶狠的表情对我说："你很有钱啊。"过了两年，她又因为这件事生气，前后重提了两次。
- 我上夜班，凌晨两三点才忙完，躺在床上半小时也睡不着，很痛苦。我从小床起来时，正好她上厕所回来，我说我躺了半小时都睡不着，然后去大厅沙发上躺着刷了会儿手机，直到五点才睡着。刚睡了两个多小时，她就把我叫起来，说："老师突然通知今天要站岗，我还要化妆，你去。"我说好。到了楼下，妈妈问我怎么起这么早，我说了原因，妈妈说她替我去。后来她从楼上下来，说："不是你去吗，怎么变成妈妈了？半小时都坚持不住吗？"然后我们第一次两个月都没说话。几个月后我才知道，她生气是因为觉得没面子——人在家里，却还要让我去替她站岗。
- 她说请月嫂的钱要还给爸妈，不然怕妈妈以后再提起这件事，我说好。后来差了一点钱，用的是她的（结婚后两年，我每个月都给她 3000，不含房租和奶粉，这 3000 完全由她收着）。所以每个月工资到手，我只自己留一点，其余都给她。一开始几个月我都会算还剩多少钱没还她，她说不用算这些，再后来大概也剩不了多少，我索性也忘了算。其实我心里是真的想以后都这样把钱交给老婆，自己只留一点。后来要交车险，我在卧室门口找她要钱，她生气地说："找你爸爸去。"
- 两个孩子表现实在差劲的时候，她会用手背去打孩子的脸。
- 她每天至少要对孩子大声吼几百句。有位同学的妈妈说："只要孩子不是太过分，就不用凶他们。"
- 一起过日子，本该是互相进步。可到了我这儿，错的都是我，进步的也都是我。事后认错没用，她永远说自己没错；努力进步也没用，永远是热脸贴冷屁股。
- 买自行车不行，买完了还一直念叨；养鱼不行，养仓鼠不行，买什么都不行。我在背单词，她说有什么用。我在写代码，她说能赚钱吗？
- 上夜班时，就算凌晨三点才下班，早上也是我送娃上学，我从没说什么。我还要给两个娃洗澡，她却说别人的老公都只给一个娃洗澡；还说别人家的老公会拖地，于是也让我拖地；还问我为什么不给娃辅导功课（之前我辅导孩子时，她就坐在椅子上，当着其他小朋友的面给我白眼，我当时心里瞬间的反应就是不想再教了）。
- 她妈妈之前爬梯子摔倒进了医院，花了一万多。后来她让我换天花板上那种老式二极管灯泡。当时她在吃早餐（她曾经很自豪地说自己有时能吃到十点多），我叫她有空上楼帮个忙，等了很久她也没上来，我就自己弄好了。事后她还很生气，说我叫了她两次（不知道怎么算的，实际上只叫了一次）。
- 岳母被车撞了，住在医院。我说以后你用我的车吧，反正我也是在家上班，她却说她不想要这样的爱——意思是她想让我给她单独买一辆。
- 教她开车，前两次出发前都因此吵架，教的过程中我还要挨她骂。正常都是师傅骂学员，可我明明没骂她、没说她，反倒被她骂。平时出去玩她开车，我坐副驾也只有挨骂的份，说我没提前讲清楚。她要么完全走了逆向都不知道，要么开上别人的匝道。反正错的都是我，我也懒得跟她解释为什么。
- 她去看岳母三天，我一个人在家带两个孩子，送娃去上辅导班，回来还要辅导娃录视频打卡、写作业。结果有一天娃犯拖延症，一回家就吵起来了，当时有四个亲戚过来吃饭，她还在他们面前数落我的不是。后来在床上，她用手臂挡着眼睛，慢慢哭了起来，我没有问；她还一直挡着，又提起这件事。平时孩子都是十一二点才睡，我辛辛苦苦带了三天，就一天晚睡，怎么就不行了？
- 我说出钱给她买衣服，她没回，估计是觉得男人的眼光不行吧。后来她自己买了一千多的衣服。反正买衣服都是她自己买，从不问我的意见。她喜欢潮流，旧款、经典款都不要，只穿一些奇奇怪怪的新款，说这些是今年流行的，没有别的。
- 车子只是一点点小刮擦，她觉得不好看，要叫我开去弄好，我说很小下次一起弄，她说我叫我闺蜜或者我弟弟过来开可以吗？再后来她自己刮了两个车门一个屁股，说她出3000，剩下的我出。我说夫妻之间钱的钱都一样。后面也是说叫人过来开去弄。有人也说没有漏不会生锈下次一起弄。后面吵架了，我说我负债几年了，不想要再花钱了。对女人来说，你没钱，负债是你的事，她的钱完全不透明的。
- 儿子同学和妈妈来家里玩，老婆嫌弃说她们很晚别人要洗澡了还不回家，东西都要收拾和拖地板。后面儿子同学或者她妈妈说要过来，都是避而不谈，或者当着面拍儿子手臂（示意不要说漏嘴以致于去了我们家。拍手这件事是同学妈妈跟我说的）。
